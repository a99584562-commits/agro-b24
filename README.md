# Битрикс24 для агробизнеса · интерактивная презентация

Презентация-приложение для компаний агробизнеса (продажи, много внутренних процессов, логистика):
что умеет связка «Битрикс24 + настройка + разработка» — на кейсах и живых демо.
White-label: без названий компаний, имён и фамилий из реальных проектов.

Доступ — по паролю (`src/Gate.jsx`, мягкая защита для статичного хостинга).
Стек: **Vite + React + Tailwind CSS**, без бэкенда — все демо работают на вымышленных данных в браузере.

## Разделы

| № | Раздел | Живые демо |
|---|--------|------------|
| — | Старт | обложка, боли, кликабельная карта разделов |
| 01 | Продажи | воронки (4 шт.), канбан с роботами, сезонные напоминания, калькулятор потребности |
| 02 | Смарт-процессы и БП | запуск заявки из ленты и смарт-процесс «Ремонт техники» в интерфейсе Битрикс24; журнал автоматизаций по стадиям |
| 03 | Согласования | счёт на оплату, договор, реестр договоров, отгрузка |
| 04 | Закупки | закупка со сравнением поставщиков |
| 05 | Планирование | каскадный план продаж, календарь техники |
| 06 | Логистика | рейсы и перевозчики, план отгрузок, трекер для клиента |
| 07 | Интеграции | обмен с 1С, телефония + ИИ, мессенджеры, разбор почты |
| 08 | Отчёты | дашборд план-факт, дебиторка и взыскание |
| 09 | Приложения | шахматка объектов, карта клиентов, личный кабинет |

## Управление

- **→ / ← / пробел / свайп** — листать слайды
- **«Содержание»** (слева вверху) — оглавление с переходом к любому слайду, **Esc** — закрыть
- Слайд «Карта презентации» — клик по блоку переводит в раздел
- Ссылка на конкретный слайд: `…/agro-b24/#kanban` (id слайда) или `#12` (номер)
- **Home / End** — первый / последний слайд

## Локально

```bash
npm install
npm run dev -- --port 5260
npm run build
```

Пуш в `main` публикует сайт на GitHub Pages через Actions (`.github/workflows`).
